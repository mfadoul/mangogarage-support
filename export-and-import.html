Export, backup, and import

Mango Garage gives you two different portability tools: a complete local archive for backup and restore, and a fuel spreadsheet for analysis or a guided one-time migration.

Choose the right file

NeedUseImportant limit
Complete local backup or restoreVersioned ZIP archiveThe only intended full round trip; it can retain relationships, photos, and other local record data.
Fuel-history analysis in a spreadsheetCSV or XLSX exportContains ordinary fuel values and calculations, not event photos or Cloud Assist credentials.
Bring an existing fuel table into one vehicleGuided CSV, XLSX, or ODS importImports selected raw values after preview; it does not import formulas, charts, photos, or arbitrary columns.

Fuel spreadsheet export

Settings can create a UTF-8 CSV or an XLSX workbook. Both contain selected source values, normalized values, derived calculation status, and MPG parity checks. XLSX adds filters, a frozen header row, and formula-based checks that make the workbook easier to inspect in common spreadsheet apps.

A blank calculated MPG means the record interval is not eligible for that calculation; it does not mean zero MPG. The app exports a spreadsheet for portability and review, not as a live two-way synchronization system.

Guided spreadsheet import

  1. Choose the destination vehicle.
  2. Choose a CSV, XLSX, or ODS file and review recognized columns or suggested mappings.
  3. Confirm units and preview ready and skipped rows.
  4. Import only the selected raw values.

Duplicate records are skipped rather than overwritten. Mango Garage recomputes its own derived values after import so an edited spreadsheet formula does not become authoritative vehicle data.

Current limits

  • Import reads CSV files and the first worksheet of an XLSX or ODS workbook. If a workbook cannot be read, export its first worksheet as CSV and try again.
  • A spreadsheet does not restore all Mango Garage record types and is not a replacement for a ZIP archive.
  • Spreadsheet export does not include event photos, Apple account information, or Cloud Assist sign-in details.
  • Always verify a newly created backup or export in the destination you chose before relying on it.
