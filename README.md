# Mango Garage Support

The public support, privacy, and terms pages for the Mango Garage iOS app,
published with GitHub Pages from the root of `main`. The site is static HTML and
CSS with no JavaScript, analytics, forms, or sign-in.

Support contact: `papayamedley.app@gmail.com`

## Pages

The app and App Store listing link to these paths, so keep them stable:

- `https://mfadoul.github.io/mangogarage-support/`
- `https://mfadoul.github.io/mangogarage-support/help.html`
- `https://mfadoul.github.io/mangogarage-support/privacy.html`
- `https://mfadoul.github.io/mangogarage-support/terms.html`
- `https://mfadoul.github.io/mangogarage-support/delete-account.html`
- `https://mfadoul.github.io/mangogarage-support/export-and-import.html`

Pushing to `main` republishes the site within a few minutes.
